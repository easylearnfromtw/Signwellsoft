# SIGNWELL SOFTWARE 欣緯軟體官網

靜態網站，不需要建置步驟，可以直接放到 GitHub Pages。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 頁面、樣式與程式都在這個檔案 |
| `assets/three.module.min.js` | three.js r160（MIT License），3D 場景使用 |
| `assets/w/*.webp` | 作品高解析度截圖（五張 2560 × 1600；CMS 保留原檔） |
| `assets/w/preview/*.webp` | 手機 3D 貼圖與 Lite 卡片共用縮圖，降低解碼記憶體 |
| `.nojekyll` | 讓 GitHub Pages 不經過 Jekyll 處理 |

## 部署到 GitHub Pages

1. 把資料夾裡的所有檔案（含 `.nojekyll`）放到 repo 根目錄，或放進子資料夾。
2. 到 repo 的 Settings → Pages，選擇要發布的 branch 與資料夾。
3. 部署完成後打開網址即可。

## 本機預覽

3D 程式以 ES module 載入，直接雙擊 `index.html` 會被瀏覽器擋下。請在資料夾內開本機伺服器：

```
python3 -m http.server 8000
```

再用瀏覽器開 `http://localhost:8000`。

## 手機與電腦預設 3D（2026-10-17）

具備 WebGL2 的手機與電腦現在都會直接載入 Three.js，保留首頁卡片、互動模組與集團沿革的即時 3D 動畫；不再需要在網址後加 `?full3d=1`。

- **手機的 3D 效能管理**：原始短邊目標 850px、像素倍率上限 1.5、輕量網格及材質、關閉即時陰影；如持續低於約 44 rAF fps，逐階減少繪圖解析度，最低保留原比例 65%；效能持續恢復後會逐步調高。這是渲染解析度自適應，不承諾在所有裝置達到 60 fps。
- **桌面 3D**：維持約 1440px 短邊的原有高畫質設定。
- **完整備援頁面**：當裝置不支援 WebGL2、Three.js 載入失敗、WebGLRenderer 初始化失敗、渲染出錯或 WebGL context lost，會切換到 Lite 2D 版本；保留作品、服務、團隊、互動效果示意與集團故事。
- **手動切換 Lite**：在網址後加 `?lite=1`。舊的 `?full3d=1` 已不需要；`?perf=1` 可在 3D 模式查看實測 rAF fps、渲染尺寸及品質倍率。
- **Lite 模式**：不載入 Three.js、不建立 WebGLRenderer，使用輕量 SVG 卡片、作品縮圖以及事件驅動的導航更新。

### 手機版故障排查

正常情況下手機會顯示 3D。若 3D 無法啟動，頁面會自動改用 Lite 版；也可加入 `?lite=1` 手動查看。若仍看到舊版，確認 GitHub Pages 已部署 `main`，再使用無痕視窗測試；若 3D 疊層卡片穿模，應另外針對該裝置處理深度排序與鏡頭位置，不能以永久關閉全部手機 3D 作為唯一修復方式。
