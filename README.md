# SIGNWELL SOFTWARE 欣緯軟體官網

靜態網站，不需要建置步驟，可以直接放到 GitHub Pages。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` | 頁面、樣式與程式都在這個檔案 |
| `assets/three.module.min.js` | three.js r160（MIT License），3D 場景使用 |
| `assets/w/*.webp` | 作品高解析度截圖（五張 2560 × 1600；CMS 保留原檔） |
| `assets/w/preview/*.webp` | 手機 Lite 卡片與縮圖專用尺寸，避免常駐完整截圖的解碼記憶體 |
| `.nojekyll` | 讓 GitHub Pages 不經過 Jekyll 處理 |

## 部署到 GitHub Pages

1. 把資料夾裡的所有檔案（含 `.nojekyll`）放到 repo 根目錄，或放進子資料夾。
2. 到 repo 的 Settings → Pages，選擇要發布的 branch 與資料夾。
3. 部署完成後打開網址即可。

## 本機預覽

3D 程式以 ES module 載入，直接雙擊 `index.html` 會被瀏覽器擋下。請在資料夾內開本機伺服器：

```
python3 -m http.server 8000
```

再用瀏覽器開 `http://localhost:8000`。

## 手機 Lite 模式與桌機 3D

2026-10-14 起，**手機預設使用 Lite 模式**：保留品牌視覺、作品、三名成員、服務、五項特色技術、模組展示與集團故事，但不載入 Three.js，也不建立 WebGLRenderer。模組 M06–M10 不再使用即時 3D 疊層，而使用獨立 SVG 示意與文字卡片，避免卡片互相穿插及手機 GPU 負擔。

- 手機版支援水平捲動作品卡、點選團隊與服務詳細資料、完整導覽與社群展示。
- 手機版保留首頁編排及互動示範；放大鏡取消高成本位移濾鏡，玻璃介面不使用即時背景模糊；捲動時只按需更新導覽，不再持續跑 3D 影格迴圈。
- 手機版使用縮圖 `assets/w/preview/*.webp`，不需要解碼大型作品截圖。
- **桌機維持完整 WebGL 3D**，場景使用約 1440px 短邊的繪圖解析度。
- 若要在手機測試舊的即時 3D 路線，可暫時加 `?full3d=1`；此模式已調降目標短邊至 850px、像素倍率最多 1.5 與部分材質解析度，但不作為正常手機訪客預設。
- `?perf=1` 適用於完整 WebGL 模式，可查看診斷幀率；一般手機 Lite 模式不會開啟 WebGL 幀率計數器。

此區為**品牌定位、技術應用方向與服務介紹**，不是後台 AI 功能已正式上線的聲明。網站實際功能仍以專案實作結果為準。

### 手機版故障排查

若修改後仍看到旋轉疊層卡片（例如 M07 裡多張卡片穿插），先確認網站已發布到此儲存庫的最新 `main`，再重新整理頁面，必要時以新查詢參數（例如 `?v=mobile-lite-20261014`）避免舊快取。正常手機版的 M07 應顯示一張獨立、不可穿插的輕量示意卡。
